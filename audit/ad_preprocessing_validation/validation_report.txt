METHODOLOGY TRANSPARENCY NOTE: the spatial-coverage check went through two
corrections during this validation, both caught by inspecting actual data
rather than trusting the first automated result:
  1. Initial version compared the final residual output (eres.nii.gz) against
     the raw input using a positive-intensity Otsu threshold -- this flagged
     19/25 runs with large apparent "coverage loss" (up to 37 slices). Direct
     inspection of the output's actual values showed it is a zero-mean,
     SIGNED GLM residual (min -519278, max 490717, mean ~-0.06) -- exactly
     correct after intercept removal, but a magnitude-domain threshold is the
     wrong tool for it. This was a validation-method artifact, not a pipeline
     defect.
  2. A revised residual-domain check used per-voxel temporal VARIANCE with an
     Otsu threshold -- this produced an even more alarming "0-3/48 slices
     with modeled signal" for 5 runs. Direct inspection showed the variance
     distribution is extremely heavy-tailed (median ~42,000 vs max ~1.1
     billion in one case) -- a handful of extreme-variance edge/artifact
     voxels dragged Otsu's threshold far above the bulk of real tissue
     voxels. Per-slice MEDIAN variance (robust to outliers) showed a normal,
     sensible brain-shaped profile all along. Switched to a robust
     percentile-of-median-based threshold, which resolved this.
  Both corrections are documented here, not hidden, per the instruction to
  verify actual outputs rather than trust a single computed number.
