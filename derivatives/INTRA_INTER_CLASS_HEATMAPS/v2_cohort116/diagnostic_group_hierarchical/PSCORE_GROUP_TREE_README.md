# P-Score Heatmap with Diagnostic-Group Tree

246 ROIs × 6 diagnostic groups, with a dendrogram over the groups and **no ROI
dendrogram**.

Generated by [`scripts/audit/pscore_group_tree_heatmap.py`](../../../../scripts/audit/pscore_group_tree_heatmap.py).

---

## The P-score

$$\text{P-score}_{i,s} = -\log_{10} q_{i,s}$$

for ROI *i* and diagnostic group *s*, where *q* is the Benjamini–Hochberg
FDR-adjusted p-value.

| | |
|---|---|
| Test | two-sided **Mann–Whitney U**, stage vs the pooled other five |
| Correction | **BH over 246 × 6 = 1,476 tests, per biomarker** |
| Threshold | q < 0.05, i.e. **P-score > 1.3010** |
| Source | `<biomarker>_roi_stage_qvalues.csv` (read, never recomputed) |
| Floor | 1 × 10⁻¹² before log10; **never engaged** (smallest q = 0.118) |

Higher P-score = stronger statistical evidence. Lower = weaker.

rescaled. The upper bound sits above the threshold so q = 0.05 is always
visible on the colourbar — and visibly unreached.

## What the heatmap and the dendrogram each encode

**Both come from the same P-score matrix.** The dendrogram clusters the six
diagnostic groups by their **246-dimensional P-score profiles** — how similar
their *pattern of statistical evidence* is across regions. It is labelled
**"diagnostic-group clustering by P-SCORE PROFILE"** on every figure.

This is deliberately **not** the biomarker-profile dendrogram in
[`DIAGNOSTIC_GROUP_HIERARCHICAL_README.md`](DIAGNOSTIC_GROUP_HIERARCHICAL_README.md),
which clusters the same six groups by their mean regional biomarker
**activity**. The two answer different questions and generally give different
trees. Putting a biomarker-derived tree on top of a P-score heatmap would place
two different quantities in one figure without saying so, which is why it was
not done here.

| Setting | Value |
|---|---|
| Objects | 6 diagnostic groups |
| Input | 246-D P-score profile per group |
| Distance | **correlation** (1 − Pearson r) |
| Linkage | **average** (UPGMA) |
| Ordering | `scipy.cluster.hierarchy.optimal_leaf_ordering`, deterministic |

### Leaf order and tree fidelity

| biomarker | dendrogram leaf order | cophenetic *r* |
|---|---|---:|
| mALFF | MCI, EMCI, LMCI, CN, AD, SMC | 0.757 |
| mReHo | CN, LMCI, EMCI, AD, SMC, MCI | 0.858 |
| DC_z | LMCI, AD, CN, SMC, MCI, EMCI | 0.768 |

Canonical labels and source indices are preserved in

**Clinical progression order remains `CN → SMC → EMCI → MCI → LMCI → AD`** and
is printed on every figure. The dendrogram order differs from it, which is
expected: the tree reflects unsupervised similarity of evidence under the
chosen metric, **not a disease-progression pathway**.

## Limitations

- **Nothing is significant.** With no cell passing FDR, the P-score surface
  being clustered is dominated by sampling noise, and the dendrogram should be
  read as a display ordering rather than a result.
- **A tree is not a test.** Branch heights are distances, never p-values.
- **Similar evidence is not similar biology.** Two groups can cluster together
  simply because both produced weak evidence in the same regions.
- **FC's tree is weakly supported** (cophenetic r = 0.582).
- Sample size: 116 subjects, 16–20 per stage, against a 1,476-test family.
- Cross-sectional design — no progression claim is supported.

## 7. Figure variants in `figures/` — what each annotates

Four sets exist. None overwrites another; all share the same heatmap and the
same statistics.

| files | branch labels | above the tree |
|---|---|---|
| `pscore_grouptree_<bm>.*` | none | none |
| `pscore_grouptree_dist_<bm>.*` | `d =` merge distance | none |
| `pscore_grouptree_annotated_<bm>.*` | `d =` + `q*` selective | none |
| `pscore_grouptree_groupscore_<bm>.*` | none | **per-group P-scores** |

### The per-group annotations, defined exactly

Each group in `pscore_grouptree_groupscore_*` carries two numbers:

**`P = ...` — a genuine MULTIVARIATE group-level P-score.**
`-log10(q)` where q comes from `one_vs_rest_statistics.csv`: the stage-level
one-vs-rest test, distance-based pseudo-F over **all 246 ROIs jointly**,
9,999 permutations, Benjamini-Hochberg across the full **4 biomarkers x 6
stages = 24** family. This is a real statistical test of "is this stage
separable across all regions at once?", and it is **one valid value per
group** — not derived from the heatmap cells.

**`max ROI P ...` — DESCRIPTIVE only.**
The largest P-score in that group's heatmap column. It is the maximum of 246
already-FDR-corrected values, **not itself a test**, and is labelled as such
on the figure in grey italic. It answers "what is the strongest single-region
evidence for this group?" and nothing more.

**No average of ROI P-scores is shown anywhere.** Averaging corrected
significance values would produce a number with no inferential meaning, and
was deliberately avoided.

**The two annotations are different tests on different units**, corrected in
different families (24 vs 1,476). They are never summed, averaged, or
compared with one another.

### Results

| | |
|---|---|
| Groups with multivariate q < 0.05 | **0 of 24** |
| Largest multivariate P-score | **0.8564** |
| Largest max-ROI P-score | **0.9278** |
| Threshold | **1.3010** |

**Neither annotation reaches the threshold for any group in any biomarker.**
Verified against `one_vs_rest_statistics.csv` and the four
`<bm>_roi_stage_qvalues.csv` files to the stored 6-decimal precision
(max |difference| 4.8e-07).

Per-group values are tabulated in `csv/group_level_pscore_annotations.csv`,
which carries the test description and the descriptive caveat on every row.

## 8. Combined four-panel P-score figure

`figures/pscore_hierarchical_combined_4panel.{png,pdf}` — **one** figure, four
panels (A mALFF, B mReHo, C DC_z, D Functional Connectivity). Script:
`scripts/audit/pscore_combined_four_panel.py`. Leaf order:
`csv/pscore_combined_4panel_leaf_order.csv`.

This is the P-score counterpart of `group_hierarchical_combined.png`, which
shows standardised biomarker means. **Same layout, different quantity.**

### Values

$$\text{P-score} = -\log_{10} q$$

where *q* is the stored Benjamini–Hochberg FDR-adjusted p-value from the ROI ×
stage analysis (two-sided Mann–Whitney U, stage vs pooled rest, BH over
246 × 6 = 1,476 tests per biomarker). Read from
`<biomarker>_roi_stage_qvalues.csv`, never recomputed. Every panel validated as
a **246 × 6** matrix with column headers matching `CN, SMC, EMCI, MCI, LMCI, AD`
before plotting.

### Colour scale — why not the Z-score red–blue

Sequential **YlOrRd**, fixed **0.0–1.40**, identical in all four panels.

The diverging red–blue scale used for Z-scores is **not** reused here, and
deliberately so: P-scores are non-negative and have no meaningful midpoint, so
a diverging map centred on zero would imply a sign distinction that does not
exist and would visually exaggerate near-zero values. The upper bound sits
above the threshold so **q = 0.05 → 1.3010** is always on the colourbar, marked
with a black line.

### Clustering — per biomarker, independently

| | |
|---|---|
| Input | the six groups' **246-D P-score profiles** (never raw biomarker values) |
| Distance | correlation, 1 − Pearson *r* |
| Linkage | average (UPGMA) |
| Ordering | `optimal_leaf_ordering`, deterministic |

Heatmap columns follow each panel's own leaf order, so **row positions are
comparable across panels but column positions are not**. The colour scale *is*
comparable. Canonical labels and source indices are preserved in the CSV.

| panel | leaf order | cophenetic *r* | max P-score |
|---|---|---:|---:|
| A mALFF | MCI, EMCI, LMCI, CN, AD, SMC | 0.757 | 0.652 |
| B mReHo | CN, LMCI, EMCI, AD, SMC, MCI | 0.858 | **0.928** |
| C DC_z | LMCI, AD, CN, SMC, MCI, EMCI | 0.768 | 0.137 |
| D FC | EMCI, AD, SMC, MCI, LMCI, CN | 0.582 | 0.414 |

**No numerical branch labels are drawn.** Branch heights are merge distances,
not p-values; the caption states this. Distance-labelled variants exist
separately as `pscore_grouptree_dist_*`.

### Statistical result

| | |
|---|---|
| ROI-stage cells at q < 0.05 | **0 of 5,904** |
| Largest P-score anywhere | **0.9278** |
| Threshold | **1.3010** |
| Missing values | **0** |

**No ROI-stage cell reaches the significance threshold in any panel**, stated
on the figure in red. Verified against source to the stored 6-decimal precision
(max difference 4.8 × 10⁻⁷). Nothing was rescaled or altered.

### Interpretation

The tree reflects similarity of **statistical-evidence profiles**, not raw
biomarker activity and not clinical progression. DC_z appears almost blank
because its strongest evidence anywhere is P = 0.137 — that is the honest
result at this sample size, not a rendering fault. Since nothing survives FDR
correction, the clustering is a display ordering over a largely null surface
and must not be read as evidence of diagnostic-group separation.
